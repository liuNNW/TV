怎么用

① 电脑上把项目推到 GitHub / Gitee 仓库（含 dist/，服务器不用装 TypeScript）， 改完代码执行 npm run ship "更新说明" 一条命令构建+提交+推送。
② 填仓库地址和分支点「绑定仓库」；私有仓库还要填 GitHub Token。 Token 只存在服务器的 data/update-config.json，不会回显到页面，也不会进仓库。
③ 以后推完代码，打开本页会自动检查是否有新提交；点「一键更新并重启」完成 拉取 → 覆盖 → 装依赖 → 重启，页面会自动刷新。
④ 用 PM2 托管时，更新重启由 PM2 负责（不会出现两个进程抢端口）。 没装 PM2 则使用原来的自愈重启。
⑤ 公网暴露时请设置环境变量 UPDATE_TOKEN，并用 settings.html?token=你的口令 打开本页；页面会自动把口令带给更新接口。
收藏 / 历史 / 本地媒体配置 / videos 文件夹都不在仓库里，更新不会覆盖。
