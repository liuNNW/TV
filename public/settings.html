部署与更新说明
  1. 1
    电脑端推送代码到 GitHub / Gitee，推荐执行 npm run ship "更新说明"。
  2. 2
    首次使用：填写仓库地址、分支和 Token，点击「绑定并拉取仓库」。
  3. 3
    以后推送代码后，本页会自动检查；有更新时点击「一键更新」。
  4. 4
    更新完成后服务自动重启，页面会自动刷新。PM2 下由 PM2 负责拉起进程。
若服务器设置了 UPDATE_TOKEN，请用 settings.html?token=口令 打开本页。 收藏、历史、data/ 与 videos 目录不会被更新覆盖。
